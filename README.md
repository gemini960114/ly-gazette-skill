# 立法院教文委員會公報查詢

把 2026 年教育及文化委員會的公報紀錄（.doc）轉成文字並建立索引，讓 Claude Code 能用自然語言查詢「誰在哪場會議說了什麼」，回答附原文出處。

## 資料與結構

```
.agents/skills/legislative-records/   查詢 skill（.claude/skills/ 下有同名連結）
gazette_downloader/                   公報 DOC 下載程式與下載紀錄（見其 README.md）
output/legislative_communiques/
├─ 2026_DOC/DOC/                      原始 .doc（55 份，2026-01-07 ~ 08-26；不在 repo 內）
├─ 2026_MD/                           轉成文字的 md（一段一行）
└─ 2026_INDEX/                        索引：會議、委員、官員、發言段落
```

## 安裝

repo 已含轉好的 md 與索引，clone 後即可查詢，不需要 Word 或原始 .doc。

1. 讓 Claude Code 讀到 skill（skill 實體在 `.agents/skills/`，Claude Code 需要從 `.claude/skills/` 建連結）：
   ```powershell
   # Windows（PowerShell，在專案根目錄；junction 不需系統管理員權限）
   New-Item -ItemType Directory -Force .claude\skills | Out-Null
   New-Item -ItemType Junction -Path .claude\skills\legislative-records -Target (Resolve-Path .agents\skills\legislative-records).Path
   ```
   ```bash
   # macOS / Linux
   mkdir -p .claude/skills && ln -s ../../.agents/skills/legislative-records .claude/skills/legislative-records
   ```
2. 安裝 uv 後執行 `uv sync`（查詢只用標準庫；轉換 .doc 才需要 Windows 上的 pywin32）。
3. 原始 .doc 約 3.3 GB 不放在 repo；需要重新轉換時，用 `gazette_downloader/` 下載。

- 範圍：全體委員會議、聯席會議、公聽會，共 55 份檔案、約 2,100 個發言段落。
- 出處以「檔案＋行號」標示（md 的行號，不是公報印刷頁碼）。
- 8 份檔案主要是掃描圖片（預算提案表、條文對照表），沒有文字可查。

## 使用方式

在本專案開 Claude Code，直接用中文問即可；skill 會自動啟用（也可以打 `/legislative-records`）。

### 基本查詢

| 想知道 | 可以這樣問 |
|---|---|
| 某位委員 | 「吳思瑤這個會期質詢過哪些主題？」「葛如鈞問過文化部什麼？」 |
| 某位官員 | 「鄭英耀部長在哪幾場會議答詢過？」「李遠部長對 TaiwanPlus 怎麼回應？」 |
| 某場會議 | 「7 月 16 日那場會議討論什麼？誰質詢了？」「8/19 會議有哪些決議？」 |
| 某個議題 | 「哪幾場會議討論過校園食安或致癌油？」「有誰提到校護？」 |
| 兩者交集 | 「郭昱晴在 8 月的會議有沒有提到偏鄉學校？」「教育部對吳沛憶的質詢承諾了什麼？」 |
| 公聽會 | 「教育經費編列與管理法公聽會上，學者專家的主要意見是什麼？」 |

### 彙整與分析

- 「整理 TaiwanPlus 爭議的來龍去脈：哪些委員質詢、部長前後說法有沒有不同。」
- 「比較各黨委員對《偏遠地區學校教育發展條例》修法的立場，附原文引用。」
- 「列出這個會期官員說過『會研議』『會檢討』的事項，做成追蹤清單。」

### 進階範例：從機關角度整理備詢資料

> 請分析這批 2026 年教育及文化委員會公報，找出與國網中心（國家高速網路與計算中心）相關的質詢與答詢，包含直接提到國網中心、國家實驗研究院／國研院、台灣杉、創進一號、超級電腦、TAIDE、AI 算力中心、主權 AI 的段落。只提到泛用「算力」或「資料中心」、沒有涉及上述機構或計畫的（例如核能供電議題），列為「相關度低」另外表列。
>
> 先列出候選段落清單（日期、會議、立委、行號、相關度）讓我確認，再進行完整整理。
>
> 完整整理依「立委、日期、會議、議題、具體問題、答詢機關與人員、答覆重點、承諾事項、期限、後續追問」做成表格，每列附原文短引與「檔案＋行號」。分開標示口頭質詢、書面質詢、機關書面報告。
>
> 最後從國網中心角度，列出最需要準備的十個備詢問題，以及每題應備妥的數據或佐證。請清楚區分「公報有記載」與「分析後建議」；公報沒有記載的資訊（例如承諾期限）請標示「未查得」，不要推測。

### 國網中心情境範例

從小問題開始，確認結果正確後再要求整合報告：

| 目的 | 可以這樣問 |
|---|---|
| 特定委員 | 「葛如鈞委員這個會期對國科會問過哪些 AI 算力、TAIDE、AI Token 的問題？逐場列出，附行號。」 |
| 追蹤承諾 | 「整理國科會在教文委員會答應『會後提供資料』或『X 個月內提出規劃』的事項，標出答應的人、日期、期限，以及和國網中心業務的關係。」 |
| 批評與回應 | 「委員對 TAIDE 提出哪些批評？列出具體測試案例和國科會的回應。」 |
| 數字口徑 | 「公報裡提到國網雲端算力中心的規模和算力目標（MW）有哪些數字？各是誰在什麼場合說的？」 |
| 預算與管理 | 「有哪些委員在預算審查中提到國網中心或國研院（凍結、財產管理、設施事故）？結果是什麼？」 |
| 預測備詢 | 「根據葛如鈞過去的發言，如果他下次質詢國網中心，最可能問哪些問題？請區分『公報記載』和『分析推測』。」 |

小提醒：只打「國網」會誤中「中國網路」「韓國網路」「中華民國網球」。請用「國網中心」或完整名稱。另外，原文把「創進一號」誤植為「創近一號」，查詢時兩種寫法都要包含。

### 更新資料

- 「我加了新公報」：轉換新的 .doc 並重建索引，回報新增了哪幾場會議。
- 新檔案請放進 `output/legislative_communiques/2026_DOC/DOC/`，檔名以會議日期開頭，例如 `2026-09-02_教文_..._LCIDC01_1158001_00003.doc`。
- 只收 .doc / .docx；PDF 請改下載同一份紀錄的 DOC 版（立法院兩種都有提供）。

## 測試項目

| # | 測試 | 問法（範例） | 預期結果 |
|---|---|---|---|
| 1 | 委員查詢 | 「葛如鈞在 7/16 問了李遠部長什麼？」 | 找到第 20 次會議、9時16分起的質詢段落，附行號與原文引用 |
| 2 | 官員答詢 | 「李遠部長怎麼解釋 TaiwanPlus 是災難的說法？」 | 引用部長原話，並區分委員提問與部長答覆 |
| 3 | 議題搜尋 | 「哪些會議討論過校園食安？」 | 至少找到 7/13 第 19 次（校園食品安全及致癌油專題報告） |
| 4 | 會議與決議 | 「7/13 那場會議的議程和決議？」 | 列出議程與決議，不把開頭宣讀的上次議事錄算進來 |
| 5 | 跨場次彙整 | 「整理 TaiwanPlus 爭議，部長前後說法有沒有不同？」 | 涵蓋 5/7 第 9 次、7/13 第 19 次、7/16 第 20 次，每點附出處；7/2 預算審查（部長說「災難」那天）的檔案主要為圖片，應說明當天原話查不到，只能從後續會議的轉述得知 |
| 6 | 進階範例 | 上方「國網中心備詢」範例 | 先給候選清單；表格每列有行號引用；「公報有記載」與「分析後建議」分開；查不到的標示「未查得」 |
| 7 | 檔名次別錯誤 | 「第 23 次全體委員會議討論什麼？」 | 能找到檔名寫「第22次」的 `1156701_00004`（內文標題才是第 23 次） |
| 8 | 續頁 | 「8/19 偏遠地區學校教育發展條例的逐條審查內容？」 | 找到第 27 次的續頁 `1157501_00006` 並以第 27 次稱呼 |
| 9 | 圖片檔 | 「5/18 第 10 次會議的預算提案內容？」 | 說明該份主要為掃描圖片、沒有文字可查，指出是哪份檔案 |
| 10 | 姓名錯字 | 「吳沛憶發言過幾次？」 | 原文誤植的「吳委員憶沛」也算在吳沛憶名下 |
| 11 | 查無資料 | 「教文委員會討論過核融合發電嗎？」 | 回答「目前收錄的紀錄中沒有找到」並說明查了哪些關鍵字，不用一般知識補 |
| 12 | 新增資料 | 放一份新 .doc 後說「我加了新公報」 | 只轉換新檔、重建索引，回報新增的會議 |
| 13 | 委員主題彙整 | 「葛如鈞對國科會問過哪些算力和 TAIDE 的問題？」 | 至少涵蓋 4/8 第 5 次（算力 MW 與 GW、AI Token、Token 翻譯）、4/29 第 8 次（TAIDE 錯誤回答、公私協力、Token 預購、臺灣用語語料庫）、5/6 第 9 次（2029 年 23 MW 目標、算力預購） |
| 14 | 承諾追蹤 | 「國科會答應葛如鈞哪些事、期限多久？」 | 列出各承諾與期限，例如 Token 激勵方案（5/8 前提供）、公私協力規劃（兩個月）、語料庫（三個月）；是否已經兌現應標示「公報未記載」 |
| 15 | 關鍵字雜訊 | 「公報裡提到國網中心的地方有哪些？」 | 排除「中國網路」「韓國網路」「中華民國網球」等誤中項目 |
| 16 | 拒收 PDF | 放一份 .pdf 後說「我加了新公報」 | 不轉換，提示改下載 DOC 版 |

## 已知限制

- 出處是 md 行號，不是公報印刷頁碼。
- 掃描圖片內容（預算提案、條文對照表）沒有文字，不做 OCR。
- 轉換需要 Windows + Microsoft Word；Mac / Linux 可改用 LibreOffice（未實測，見 `extract_doc_md.py` 說明）。
- 刪除 .doc 時，要一併刪除 `2026_MD/` 中同名的 md，再重建索引。
